Title : Banking Application System

Objective : 
    To build console-based Banking Application system that allows user to manage Account and basic operations.

Features : 
    1. Deposit
    2. Withdraw
    3. Balance Inquiry
    4. Show Transaction History
    5. Exit
    

Technologies :
    1. Java
    2. Java Collections Framework(ArrayList)
    3. Object Oriented Programming
    4. Exception Handling
    5. VS Code
    6. GitHub

File Structure :

    banking_application
    |
    |---src/
    |   |--BankAccount.java
    |   |--BankingApp.java
    |   |--Main.java
    |
    |---README.md
