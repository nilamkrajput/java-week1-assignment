Title : Java Collections Challenge

Objective : 
    To improve familiarity with java collections and their use.

Features : (ArrayList)
    1. Add Elements
    2. Remove Elements
    3. Update Elements
    4. Search For Element
    5. Iterate for an Element

Features : (HashMap)
    1. Insert Key-value pairs
    2. Retrieve a value using a key
    3. Update a value
    4. Check whether a key exists
    5. Iterate through entries

Features : (Queue)
    1. Add items to queue
    2. Remove items from queue
    3. Peek at the front item
    4. Display queue contents
    
    
Technologies :
    1. Java
    2. Java Collections Framework(ArrayList, HashMap, Queue)
    3. Object Oriented Programming
    4. VS Code
    5. GitHub

File Structure :

    java_collections_challenge
    |
    |---src/
    |   |--ArrayListChallenge.java
    |   |--HashMapChallenge.java
    |   |--QueueChallenge.java
    |
    |---README.md

Steps to complie and run :
        To compile : javac ArrayListChallenge.java, javac HashMapChallenge.java, javac QueueChallenge.java,
        To run : java ArrayListChallenge, java HashMapChallenge, java QueueChallenge
